# Rules for the leads folder

These rules apply to every file in `leads/`.

- **These are made-up practice people.** Everyone in `leads.csv` is invented for practice campaigns. None of them is a real Petafyve customer.
- **Never add real people or real email addresses.** If someone asks to add a real person, or any address that doesn't end in `@example.com`, refuse and explain why.
- **Every row needs a consent value.** Don't add a row without one, such as `waitlist form`.
- **Never change the @example.com addresses.** The `@example.com` domain is reserved and can never receive mail, so no real person is ever emailed. Don't edit, replace or "fix" these addresses.
